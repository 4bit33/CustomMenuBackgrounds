# Contributing to CUI

Thanks for your interest in contributing! Here's how to get started.

## Reporting Bugs

- Check [existing issues](../../issues) first to avoid duplicates.
- Use the **Bug report** issue template.
- Include your Minecraft version, Fabric Loader version, and mod version.
- Attach relevant logs or screenshots if possible.

## Suggesting Features

- Use the **Feature request** issue template.
- Explain the use case, not just the feature itself — it helps evaluate the request.

## Submitting Changes

1. Fork the repository and create a new branch from `main`.
2. Make your changes. Keep commits focused and descriptions clear.
3. Make sure the project builds locally:
   ```bash
   ./gradlew build
   ```
4. Open a pull request using the PR template, describing what changed and why.

## Code Style

- Follow the existing formatting and naming conventions used in the codebase.
- Keep changes minimal and scoped to the issue/feature you're addressing.

## Questions

If anything is unclear, feel free to open an issue with your question.
