# Security Policy

## Supported Versions

Only the latest released version of CUI is actively supported with fixes.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this mod (for example, something that could allow arbitrary code execution, file access outside the mod's intended scope, or similar issues):

1. **Do not** open a public issue describing the exploit.
2. Report it privately via GitHub's [Security Advisories](../../security/advisories/new) feature, or contact the maintainer directly through GitHub.
3. Include as much detail as possible: affected version, steps to reproduce, and potential impact.

You can expect an initial response within a few days. Once confirmed, a fix will be prioritized and a new release published, with credit given to the reporter (unless you prefer to remain anonymous).
